## About the Data
The included `suseo_shops_sample.csv` contains public business data for Suseo-dong, Gangnam-gu, South Korea. 
When ingested, Langent will:
1. Vectorize these stores semantically.
2. Position them in a 3D point cloud based on their semantic clusters.
3. Link them to graph entities if a Knowledge Graph (Neo4j) is connected.
